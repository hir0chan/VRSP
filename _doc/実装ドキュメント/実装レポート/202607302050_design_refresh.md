# トップページデザイン刷新(ライトテーマ化) 実装レポート

日付: 2026-07-30
対象計画書: `202607302029_design_refresh.md`

## 実装内容

ユーザー指示「トンマナが重すぎる。もっと明るく軽い方向に」を受け、トップページをダークテーマから**ライトテーマ**へ全面刷新した。キャッチコピー・画面構成・データ層は不変。

- デザインコンセプト「**昼の VRChat ワールド**」: 空色ニュアンスの白地(#F6F9FB)+ 白カード + 赤アクセント。デザイントークン(CSS カスタムプロパティ)で全スタイルを構成
- 見出し・ブランドに Google Fonts「**Zen Maru Gothic**」(丸ゴシック=明るく親しみのある声)を導入。本文はシステム和文サンス
- サムネイル SVG 4点を明るい昼景(空・雲・山・太陽のパステル)に差し替え
- アクセシビリティ: 全テキスト配色 WCAG AA 充足(赤を `--accent`(装飾・大文字用)と `--accent-deep`(白抜き地・小文字用 #C22F36)の2トークンに分離)、`:focus-visible`、`prefers-reduced-motion` 対応
- README §10 を「明るく軽いライトテーマ」に更新

## 決めた仕様(ユーザー確認用)

- **フォント**: Zen Maru Gothic を採用(候補には M PLUS Rounded 1c もあり。実物を見て変更可)。Google Fonts への外部依存が初めて入ったが、取得失敗時はシステムフォントで表示継続することを検証済み
- **赤の使い分け**: 鮮やかな赤(#E8484E)はヒーロー強調・装飾のみ、ボタン・バッジ・小さい赤文字はやや深い赤(#C22F36)。コントラスト基準(WCAG AA)充足のため
- **ライト単一テーマ**: ダーク対応(prefers-color-scheme)は将来課題として意図的に非対応

## コードレビュー修正(Claude レビュー → codex 修正)

1. ヒーロー背景の `100vw` がスクロールバー幅を含み 9px の水平オーバーフロー → `html { overflow-x: clip }` で解消(実測で横スクロール不可を確認)
2. LIVE バッジがサムネ SVG 内のラベル文字と重なる → SVG 側のラベルを削除
