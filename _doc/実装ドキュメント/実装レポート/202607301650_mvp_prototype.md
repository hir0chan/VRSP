# VRChat Schedule Portal MVPプロトタイプ 実装レポート

日付: 2026-07-30
対象計画書: `202607301624_mvp_prototype.md`

## 実装内容

- Astro 静的サイト、strict TypeScript 設定、GitHub Pages の `/VRSP/` base を追加
- 架空配信者5名と、live 2件 / 本日3件 / 翌日以降4件 / ended 2件の決定的モック生成を追加
- YAML の必須項目・型・ID重複検証と、一時ファイルから rename する generated 更新処理を追加
- JST 基準の live / TODAY / UPCOMING 分類、未知の配信者IDの警告・スキップを追加
- 日本語、ダークテーマ、赤アクセント、レスポンシブ対応のトップページを追加
- SVG サムネイルプレースホルダーと favicon を追加
- `node:test` による分類、モック生成、設定異常、書込失敗のテストを追加
- push と手動実行を分けた GitHub Pages 更新・デプロイ Workflow を追加

## 決めた仕様

- 架空配信者名は「ネオン・ハーバー」「木漏日ラボ」「ルナ・パレット」「バーチャル・ピクニック」「ミッドナイト・オービット」とした
- サムネイルパスは generated 内では base を含まない相対パスとし、表示時に Astro の `BASE_URL` を付与する
- TODAY に予定がない場合と UPCOMING に予定がない場合は、日本語の空状態を表示する
- モックの時刻は実行時刻を基準とし、JST の日付終了直前でも TODAY 3件を維持する設定とした

## ご確認いただきたい事項

1. **配信者リストの方針変更**: 当初合意の「実在配信者を Claude が仮選定」から、**MVP は架空配信者5名**に変更しました。理由: 実在配信者の名前で架空のモック配信予定を公開ページに表示するのは誤解を招くため(codex レビュー指摘を採用)。実在リストは API 連携フェーズで channelId 検証とセットで登録します
2. **render.ts / youtube.ts は未作成**: README §4 に記載がありますが、render.ts は Astro と役割重複のため作らない方針、youtube.ts は API 連携フェーズで新設します(未実装スタブによる空データ上書き事故防止のため)
3. **GitHub Actions の schedule(15分毎)はコメントアウト中**: モック期間中は生成データが毎回変わり無駄なコミット・デプロイが積み上がるため。API 連携フェーズで有効化します
4. **リポジトリは public 想定**: GitHub Pages 無料公開のため public リポジトリが前提です
