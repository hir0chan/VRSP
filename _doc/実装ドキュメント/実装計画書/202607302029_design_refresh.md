## 1. 背景・目的

MVP プロトタイプのデザインについてユーザーから方向転換の指示があった:

> 今は全体的にトンマナが重すぎます(ダークテーマ調なのも良くない)。キャッチコピーなどは素敵です。VRChat はコミュニケーションこそがメインの「明るい」ゲームだと私はみなしています。もっと明るく軽い方向性に WEB デザインを見直してください

これに基づき、トップページを**明るく軽いライトテーマ**へ刷新する。キャッチコピー(「今日、バーチャルのどこへ行く?」等)と画面構成(NOW ON LIVE → 本日 → 今後)は維持する。あわせて README §10(ダークテーマ指定)をユーザー指示の新方針に合わせて更新する。

デザイン検討には artifact-design スキルの原則(トークン設計・タイポグラフィペアリング・AI定番デザインの回避・主題に根ざした選択)を適用した。

### デザイン方針(コンセプト: 「昼の VRChat ワールド」)

行き先を探すポータルなので「晴れた日にワールドを巡る」明るさを主題にする。暗色の重さを排し、白ベース + 空色ニュアンスのニュートラル + 赤アクセント(README「アクセントは赤のみ」は維持)で構成する。

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#F6F9FB` | ページ地(空色に寄せた白。素の白/グレーを避け「選んだ」ニュートラルに) |
| `--surface` | `#FFFFFF` | カード地 |
| `--ink` | `#22323E` | 本文・見出し(青みのある濃色。純黒は使わない) |
| `--ink-soft` | `#5C6E7B` | 補助テキスト |
| `--accent` | `#E8484E` | 大きな表示テキスト(ヒーローの強調等 24px 超 bold。AA 大文字基準 3:1 は充足)と装飾のみ。**小さいテキストや白抜き文字の地色には使わない** |
| `--accent-deep` | `#C22F36` | 白抜き文字を載せる地(視聴ボタン・LIVE バッジ: 白との比 ≈5.4:1)および小さい赤文字(eyebrow・配信者名: `--bg` 上で ≈5.1:1)。WCAG AA 4.5:1 を充足 |
| `--accent-tint` | `#FDEFEF` | 赤の淡色地(バッジ背景等) |
| `--sky` | `#EAF4FB` | ヒーローの空ウォッシュ・サムネ地・日付チップ地 |
| `--line` | `#E2EAF0` | 罫線・カード枠 |

- **タイポグラフィ**: 見出し・ブランド・eyebrow に Google Fonts「Zen Maru Gothic」(丸ゴシック=明るく親しみのある声。コミュニケーション主体という主題に合わせた選択)、本文はシステム和文サンス(Hiragino 等)スタック。時刻数字は `font-variant-numeric: tabular-nums`。外部フォントは 1 ファミリーのみ(軽さ優先、weight 500/700 のみ)
- **レイアウト**: 現行の3セクション構成・カードグリッドを維持。カードは白地 + `--line` の細枠 + ごく浅いシャドウ、角丸は 14px に統一。ヒーロー上部にのみ `--sky` → 透明の淡いウォッシュ(紫青グラデ等の定番ヒーローは不採用)。LIVE カードの存在感はサイズと赤バッジで担保
- **サムネイル SVG**: 現行の暗色3種 + favicon を明るい昼景(空・雲・パステルのワールド図形)に差し替え
- **テーマ**: **ライト単一テーマ**(意図的な選択。prefers-color-scheme 対応は将来課題)。`color-scheme: light` を明示し、現行の `color-scheme: dark` を含む旧ダーク CSS を全削除する
- **モーション**: hover の軽い持ち上がり(カード)と視聴ボタンの色変化のみ。`prefers-reduced-motion: reduce` では transition だけでなく **transform・scale による移動/拡大自体を無効化**する
- **フォーカス**: カードリンク・視聴ボタンに `:focus-visible` スタイル(`--accent-deep` の 2px アウトライン + オフセット)を定義し、hover と同等に判別可能にする

| 文言 | 既存コピーを維持。hero の説明文・空状態文言もそのまま |

## 4. 実装設計

- `Layout.astro`: Google Fonts link(Zen Maru Gothic 500/700)を head に追加。ヘッダー/フッターは白地 + 罫線区切りに
- `global.css`: `:root` トークン定義 → 全コンポーネントスタイルをトークン参照で再構成。セレクタ特異度は現行構造を踏襲
- `LiveCard/StreamCard`: 視覚スタイルのみ変更(構造・Props 不変)。LIVE バッジは赤地白字を維持(明地上でのコントラスト確保)
- SVG: 手書きの長いパスは避け、単純図形(円・多角形・グラデ)で構成
- README §10: 「シンプル。**明るく軽いライトテーマ**。アクセントは赤のみ。ホロジュールを参考にするがコピーしない。レスポンシブ対応。」に更新

## 5. 検証計画

1. `npm run check` 0 errors / `npm test` 全パス(ロジック無変更の回帰確認)/ `npm run build` 成功
2. dev サーバー + chrome-devtools で 1280px / 375px スクリーンショット確認: 3セクション表示、カード・バッジ・チップの視認性。**全テキスト配色**が WCAG AA(小テキスト 4.5:1 / 大テキスト 3:1)を満たすことをトークン表の組み合わせで机上確認 + 実画面で目視確認
3. **ライブ0件の表示確認**: 既存テストは分類結果のみの担保のため、検証前に `data/generated/streams.json` を退避コピーし、live を除いた一時データで dev サーバーを表示して NOW ON LIVE セクションが描画されないことをブラウザで確認。**成否にかかわらず退避コピーをそのまま書き戻して復元**する(update 再実行では時刻依存で厳密復元できないため)
4. **フォント遮断時のフォールバック**: chrome-devtools で fonts.googleapis.com をブロック(またはオフライン)にして再読込し、システムフォントで可読・レイアウト破綻なしを確認
5. **キーボード操作**: Tab 移動で視聴ボタン・カードリンクに `:focus-visible` の可視フォーカスが出ること、Enter で遷移することを確認
6. `prefers-reduced-motion: reduce` エミュレートで hover 時の移動・拡大が発生しないことを確認

## 6. 影響範囲・リスク
