## 概要

サイトを `https://hir0chan.github.io/VRSP/` から独自ドメイン **`https://vcha-antenna.com/`** へ移行した。ドメインは Cloudflare Registrar で取得(ユーザー実施)、DNS・コード変更・GitHub Pages 設定・切替・検証まで完了。**移行は成功し、新旧 URL とも正常稼働中**。

## 実施内容

1. **DNS(Cloudflare API)**: apex / `www` とも CNAME `hir0chan.github.io`(DNS only、apex は CNAME 平坦化)。API トークンは `.env` の `CLOUDFLARE_API_TOKEN`(Zone DNS 編集権限・当該ゾーン限定)
2. **コード変更**: `astro.config.mjs`(`base: "/"`, `site: "https://vcha-antenna.com"`)、`Layout.astro` フォールバック、`digest.ts` の `SITE_URL`、`public/sitemap.xml`、テスト(digest の URL 断言・thumbnail のルート base ケース追加)、README・CLAUDE.md
3. **切替**: 事前ゲート(ローカル test/check/build 全パス・CI 実行なし・cron 窓回避)→ コミット → `gh api` で Pages カスタムドメイン設定 → push → デプロイ成功を監視 → 証明書発行確認後 `https_enforced=true`

## 運用メモ

- ドメイン更新は Cloudflare の自動更新(年10ドル強)。WHOIS は自動秘匿
- Cloudflare の proxy は無効(DNS only)。証明書は GitHub(Let's Encrypt)が自動更新
- ロールバックが必要な場合: `gh api -X PUT repos/hir0chan/VRSP/pages -F cname=null`

## 確認したい事項

- Search Console を使っている(または今後使う)場合、新ドメインのプロパティを追加して `https://vcha-antenna.com/sitemap.xml` を登録すると検索インデックスの移行が早まります(任意・ユーザー作業)
- X のプロフィール等に旧 URL を記載している場合は新 URL への差し替えを推奨します(旧 URL もリダイレクトされるため必須ではありません)
