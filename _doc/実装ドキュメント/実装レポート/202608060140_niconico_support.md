# ニコニコ生放送対応 実装レポート

日付: 2026-08-06_01:40
計画書: `_doc/実装ドキュメント/実装計画書/202608060108_niconico_support.md`(提案型→計画型。技術検討・確定仕様とも codex レビュークリア済み、実施結果追記済み)
担当: 調査・検証 Claude / コーディング codex

## 概要

YouTube / Twitch に続く第3のプラットフォームとして**ニコニコ生放送**に対応した。公式の生放送検索 API が存在しないため、検索ページの SSR 埋め込み JSON(`embedded-data`)を15分毎に取得・検証して表示用データに合流させる。ライブに加え**配信予定(予約番組)も掲載**される(Twitch にはない)。依存追加ゼロ・認証情報不要(CI Secrets 変更なし)。

## 実装内容

- **取得**(`scripts/niconico.ts` 新規): `keyword=VRChat` の onair / reserved 2リクエスト。HTTP・Content-Type・15秒タイムアウト検証、エンティティ復号、`unknown` からの厳密な型検証。有料・フォロワー限定・NSFW タイトルパターン(twitch.ts と共通)・blocklist(`nico-{supplierId}`)を除外。onair/reserved 重複は live 優先、upcoming は30日窓。UA は素性明示のボット UA(実通信で動作確認済み)
- **フェイルソフト**: どちらか一方のpage取得・解析が失敗したらその回のニコ生分を丸ごと省略(警告ログ)。YouTube / Twitch への影響なし。`totalCount > 取得件数` は警告(黙った切り捨てをしない)
- **統合**(`scripts/update.ts`): 3つの書込経路すべてに合流し参照整合検査の対象化。追跡0件+クールダウン時の書込判定を「Twitch またはニコ生の成功」に拡張
- **UI**: サムネ左下チップはテキスト「ニコ生」、フィルタセグメントに「ニコ生」追加(8状態の空グループ非表示 CSS に拡張)
- **テスト**: 実 HTML を**匿名化した fixture** に基づく9テスト(復号・型検証・除外・重複・30日窓・異常系)を新設。既存テスト2件を仕様変更に追随。計53件

## 検証

`npm run check` 0 errors・`npm test` 53件全パス・`npm run build` 成功。モックモードでニコ生架空データ3件生成。**実データモードで実ニコ生番組(ライブ2件+予定1件)の取得・表示を確認**(YouTube 89件・Twitch 55件と共存)。ブラウザでチップ表示・セグメント切替・日本語のみ併用・localStorage 復元を確認。

## 運用上の注意

- **非公式データ源**のため、ニコニコ側のページ改修で取得が壊れうる。壊れた場合はニコ生分のみ非表示になり、CI ログに警告が出る(サイト全体は無事)
- 規約変更や権利者からの要請があれば掲載を停止する運用(計画書 §2-1-4 の合意事項)

## ユーザーに確認したい事項

- ニコ生の掲載は「ニコ生検索で VRChat に一致した番組」をそのまま採用しています(合意どおり)。実データではタイトルに VRChat を含まない番組(説明文・タグ一致)も掲載されます。ノイズが目立つようなら追加フィルタを検討します
- 公式ロゴの利用条件(ニコニ・コモンズのガイドライン)が確認でき次第、テキストバッジ「ニコ生」からロゴ表示に切替可能です
