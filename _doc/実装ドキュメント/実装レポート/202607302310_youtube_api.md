# YouTube Data API 連携(ローカル実データ確認) 実装レポート

日付: 2026-07-30
対象計画書: `202607302100_youtube_api.md`

## 実装内容

- `scripts/youtube.ts`: YouTube Data API v3 クライアント。search.list を使わないクォータ節約構成(channels → playlistItems → videos、5チャンネルで約7 unit/回)。配信者ごとの成功/失敗を Result 型で区別し、バッチ失敗・存在しない channelId・タイムアウト等の帰属規則を実装
- `scripts/update.ts`: `.env` 読込(引用符付き値対応)、`YOUTUBE_API_KEY` 有無での実 API/モック自動切替、失敗配信者の前回データ引き継ぎマージ、全滅時は既存データ保護で非0終了
- `src/lib/thumbnail.ts`: サムネイル URL 解決の純関数(実データ検証で発覚した「絶対 URL への BASE_URL 二重前置」バグの修正)
- `data/streamers.yaml`: 実在配信者5名に差し替え(全 channelId を API で実在検証済み)
