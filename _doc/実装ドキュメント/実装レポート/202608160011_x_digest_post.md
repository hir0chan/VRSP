## 概要

2時間毎に「新規に live になった日本語配信」のダイジェストを IFTTT Webhooks 経由で X に投稿する機能を実装した。CI の update 成功後に独立ステップとして実行し、投稿済み管理は `data/generated/digest.json`(bot コミット対象)で行う。`update.ts` の取得・書込ロジックは無変更。

## 変更ファイル

- 新規: `scripts/digest.ts` — 本体。純関数(選定・サニタイズ・文字数計算・本文組立・投稿判定・剪定)と副作用(読込・POST・原子的書込)を分離
- 新規: `test/digest.test.ts` — 12テスト(正常系・異常系・境界・悪意ある名前・CLI)
- 変更: `scripts/models.ts` — `DigestState` / `AnnouncedEntry` 追加
- 変更: `scripts/update.ts` — `isStream` / `isStreamer` の export 化のみ
- 変更: `package.json` — `npm run digest` 追加
- 変更: `.github/workflows/update.yml` — 「Post digest to X」ステップ追加(`IFTTT_WEBHOOK_KEY` と `YOUTUBE_API_KEY` の両方を注入、`continue-on-error`)+ コミットステップの差分判定を `git add` → `git diff --cached` 方式に変更(未追跡の digest.json を拾うため)

## 主な仕様(計画書 §3 のとおり)

- 投稿条件: 前回投稿から120分以上経過 かつ 新規 JP live が1件以上。0件・未達はスキップ
- 初回実行は現在の live をベースライン記録するのみで投稿しない(長時間配信の誤告知防止)
- モック誤投稿ガード: `IFTTT_WEBHOOK_KEY` と `YOUTUBE_API_KEY` のどちらかが未設定なら無条件スキップ
- 配信者名は第三者入力としてサニタイズ(制御文字除去、`@` `#` ドット類→中黒、40重み上限)。X の重み付き280文字以内に自動切り詰め
- 投稿失敗時は state 無変更で次回自動リトライ(まれな二重投稿は許容する仕様)
- キー・URL・レスポンス本文はログ・エラーに一切出さない
- `npm run digest -- --dry-run` で本文確認(投稿・state 書込なし)

## ユーザーに実施していただく作業(これが完了するまで投稿は始まりません)

1. **IFTTT でアプレット作成**:
   - If: 「Webhooks」→「Receive a web request」、Event Name は `vrsp_digest`(完全一致)
   - Then: 「X」(旧 Twitter)→「Post a tweet」、Tweet text は `{{Value1}}` のみ(Ingredient の Value1 を挿入)
   - X アカウント(当面は個人アカウント)を IFTTT に接続
2. **Webhook キーの登録**: IFTTT の [Webhooks 設定ページ](https://ifttt.com/maker_webhooks) → Documentation で表示されるキーを、GitHub リポジトリの Settings → Secrets and variables → Actions に `IFTTT_WEBHOOK_KEY` として登録
3. **動作確認の流れ**: Secrets 登録後の最初の cron 実行でベースライン記録(投稿なし、digest.json がコミットされる)→ 以降、条件を満たした実行で投稿開始。X 投稿の成否は IFTTT のアクティビティ画面で確認できる(Webhook 受付成功≠X 投稿成功のため、最初の1件は目視確認を推奨)

### 運用メモ

- 投稿頻度は最大12件/日(月360件)。IFTTT の X アクション上限(プラン別数値は非公開、過去に25〜200件/日水準)に収まる想定だが、IFTTT 側の仕様変更で投稿が止まる可能性はある(止まってもサイト本体・CI には無影響)
- キーが漏洩した場合は IFTTT 側でキーを再生成し、GitHub Secrets を更新する
- 専用アカウントへの移行時は IFTTT アプレットの X 接続を切り替えるだけでよい(コード変更不要)
- 文言(絵文字・「ほか◯件」等)は実投稿を見て調整可能(`scripts/digest.ts` のテンプレート)

## 確認したい事項

- 初回ベースライン後の最初の実投稿が意図した文面になっているか、X 上でご確認ください
- 文言・絵文字の調整希望があればお知らせください(軽微対応で修正します)
